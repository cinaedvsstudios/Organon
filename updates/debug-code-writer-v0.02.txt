CODE WRITER v0.02 DEBUG NOTES
Phase 1 layout and project-control refinement pass

SUMMARY OF THIS VERSION

This version updates the first Code Writer scaffold based on the screenshot feedback.

Main changes:

1. Moved document stats into the top CODE WRITER title box.
   - Lines, characters, and cursor line/column now sit after a red vertical divider beside the title.
   - The separate loose stats row has been removed.

2. Rebuilt the project/tab strip.
   - Project 1 is now a coloured grouped project pill/container.
   - File tabs sit inside the project group instead of floating separately.
   - The plus/new-tab button now sits in the same project/tab row.
   - Project has a collapse/expand arrow.
   - Project has an X/hide control.
   - A hidden project can be restored with the Show Project button.

3. Added project right-click menu.
   - Right-click the project pill/group to open: Edit, Rename, Properties.
   - Edit turns project edit mode on/off.
   - Edit mode makes the project pill/group pulse.
   - While edit mode is on, file tabs can be dragged to reorder them.
   - When edit mode is off, tab dragging is disabled.
   - Rename changes the project display name.
   - Properties currently gives a simple project summary toast.

4. Moved the raw navigation buttons.
   - Page Up, Bookmark Mode, and Page Down are now attached to the Raw View window instead of the far-right side of the whole app.

5. Changed preview hide/show placement.
   - Preview header now has: Visual edit off, Hide window, Refresh.
   - When Preview is hidden, an Open Preview button appears beside Repository in the top title bar.

6. Made the bottom action bar collapsible.
   - Bottom action bar now shows a small Actions handle by default.
   - It opens on hover or when clicking the Actions handle.
   - It has a lock button to keep it open.
   - Lock changes between unlocked and locked states.

7. Version/storage update.
   - App title and subtitle changed to v0.02.
   - Local working save key changed to v002 so this test does not inherit broken or messy v0.01 browser state.

KNOWN LIMITS IN v0.02

- Project edit mode currently supports tab reordering by drag/drop. It does not yet support moving tabs between multiple projects because multiple projects are not implemented yet.
- Project Properties is only a simple summary toast for now.
- Project Hide uses a Show Project restore button so the project is not permanently lost.
- Bottom action bar collapse is CSS/JS based and should be checked carefully on mobile.
- Find/replace is still not implemented.
- The full right-click raw editor context menu is still not implemented.
- Proper Extended Raw View smart grouping is still not implemented.
- Full Building Block import/merge/duplicate review is still not implemented.
- JSON Validator/Formatter has not been added yet.
