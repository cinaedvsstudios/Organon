# Function Map for Ihy v1.0.3 rebuild

This document maps high‑level features of the Ihy application to the source files that implement or support them in the **v1.0.3** rebuild.  Because the rebuild is essentially a repackaging of the last working codebase (version 0.56), many features continue to live in their original files.  No consolidation has been attempted beyond copying the existing files into the `tools/ihy/` directory.  Future consolidation work should only be undertaken once every dependency has been fully traced.

## Summary

The final build preserves all of the original source files in their unaltered form.  The main editor’s behaviour is implemented in `standalone.js` and associated HTML/CSS.  The Bass generator is implemented in `bass-generator-v054.js` and styled via `bass-generator-v056.css`.  Additional legacy files are retained to avoid breaking any hidden dependencies.  Further consolidation and refactoring should proceed only after all dependencies have been documented and tested.
