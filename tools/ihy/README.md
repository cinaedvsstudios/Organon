# Ihy v1.0.1

This is a clean function-parity package built from the original working archive.

The runtime consists only of:
- `standalone.html`, `index.html`, `icon.png`
- `css/app.css`, `css/bass-generator.css`
- `js/dom-compat.js`, `js/app.js`, `js/ui-patches.js`, `js/legacy-export.js`, `js/bass-generator.js`

Retained active features:
- editor, tracks, sections, note editing, grouping, context menus, keyboard audition, MIDI / Ihy JSON import-export;
- the original Clear/reset, status, resizer and playback glow patch;
- full rich Bass Generator;
- legacy Driving, Pumping, Root and Gallop Bass profiles;
- restored original offline reference WAV/MP3 export.

Quick Motif remains a placeholder, because no prior archive file contained a real motif generator.
