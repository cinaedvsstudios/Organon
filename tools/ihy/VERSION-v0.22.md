# Ihy v0.22 — Grouped Controls and Open-Project Analysis

## Changed

- Strengthened arrangement bar numbers to visibly bold, dark labels inside the coloured Main track/section pill.
- Removed the visible **New** button.
- Changed **Create** to invoke the existing new blank-composition flow.
- Removed the visible Library button.
- Grouped project actions and file actions into two visual button groups without the old **Project & sound** and **Files & tools** labels.
- Changed **Analyse** to show a report for the project currently open in Ihy: title, BPM, key, duration, tracks, note count, pitch range, section count and track list.
