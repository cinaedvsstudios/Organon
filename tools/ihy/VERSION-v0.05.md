# Ihy v0.05 — Layout Baseline

This standalone layout pass moves the project title, BPM and key controls into the same header row as the Ihy title and version badge on desktop.

It moves the Compose, Create, Signal, Library and Analyse tabs into a compact two-column card at the top of the left sidebar, instead of using a full-width row.

It shortens the piano-roll viewport so the keyboard is visible below it on a normal desktop screen.
