The UI Component Glossary
1. Segmented Control
Common / Slang Names: Split pill button, toggle group, button switcher, slider capsule.

Info & Usage: A horizontal group of mutually exclusive options (behaving structurally like radio buttons) housed inside a single rounded container. A moving background indicator shifts over the selected state.

Best Used For: Flipping between alternative views of the exact same content canvas (e.g., switching from "Code" view to a live "Preview").

2. Input Box with Inline Elements (Leading Icon & Trailing Action)
Common / Slang Names: Search bar with embedded icons, internal action inputs.

Info & Usage: A standard text entry box styled with absolute-positioned elements inside its boundaries. The left-side graphic is a Leading Icon (provides semantic context), and the right-side graphic is a clickable Trailing Action Button (triggers a randomizer tool, clear button, or speech-to-text).

Best Used For: Feature-rich global search rows or URL bars.

3. Collapsible Navigation Drawer (Sidebar Menu)
Common / Slang Names: Side nav, slide-out menu, vertical bar.

Info & Usage: A main navigation panel anchored to the left or right screen edge. It usually supports an expanded state showing full text labels, and a collapsed "mini-variant" state displaying only icons to preserve precious viewport workspace.

Best Used For: Application dashboard layout frameworks.

4. Accordion with Choice Chips
Common / Slang Names: Expandable drop-downs, menu filter drawers with tags.

Info & Usage: The outer wrapper is an Accordion—a vertically stacked menu list that uses disclosure chevrons to reveal hidden content panes. Inside the pane sit Choice Chips (or selection tags/pills) that let users toggle attributes or filter properties on or off instantly.

Best Used For: Multi-layered e-commerce filters or deep settings sidebar panels.

5. Combobox Popover (Autocomplete / Typeahead Dropdown)
Common / Slang Names: Searchable popup menu, drop-down filter panel.

Info & Usage: A dynamic contextual overlay panel triggered by typing into a text field. As you input strings, an embedded query script intercepts the event and filters downstream target assets (like actions, users, or files) in real time.

Best Used For: Contact taggers, global quick-action launchers, or omni-boxes.

6. Floating Action Button (FAB) with Notification Badge
Common / Slang Names: Sticky widget button, fixed floaty bubble with red dot.

Info & Usage: A high-emphasis circular button locked to a fixed coordinate over the page canvas (typically the bottom-right viewport cluster). The overlapping red counter is a Notification Badge used to track unread system alerts.

Best Used For: The singular primary interface utility, like triggering an automated support chat workspace.

7. Range Slider & Custom Select Dropdown
Common / Slang Names: Value adjusters, input range bars, drop-down menu selectors.

Info & Usage: The left controls are Range Sliders, consisting of a continuous track track and an interactive thumb node to change numeric parameters visually. The right option is a styled HTML Select element wrapped in a custom block container to maintain application design harmony.

Best Used For: Audio/Video setting dashboards, system asset options, or configuration control tables.

8. Persistent Bottom Sheet (or Sheet Footer Bar)
Common / Slang Names: Folder tab overlay, sticky control bar.

Info & Usage: An overlay surface component anchored cleanly to the bottom floor of a window, component wrapper, or viewport context, offering primary submission call-to-actions (CTAs).

Best Used For: Finalized item mutations, modal confirmations, or mobile utility option drawers.

9. Container Card with Status Accent Border
Common / Slang Names: Stripe-sided block, colored callout block.

Info & Usage: A modern content Card component wrapped with a thick, high-contrast structural left vertical border. This border serves as a secondary semantic flag to communicate operational status (e.g., blue for neutral information, green for success, red for failures).

Best Used For: Application data drop-zones, toast notification boxes, or system dashboard status items.

10. Text Button with Leading Icon
Common / Slang Names: Action icon button, text button inline icon.

Info & Usage: A clean action text string matched with a graphic icon set directly to its left (leading position). This layout configuration helps speed up a user's visual comprehension of what the script does before they read the actual phrase text.

Best Used For: Low-to-medium emphasis content mutations or general form control pathways.
