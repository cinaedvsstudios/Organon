📐 Interface Architecture & Color Token Blueprint

Naming conventions, design tokens, and color contrast rules for modern dark-themed web interfaces.

🏷️ CLASSIFICATION & NOMENCLATURE

1. Popover vs. Tooltip vs. Modal

* Tooltip: Tiny, non-interactive, hover-triggered inline label showing simple descriptors (e.g. "Save layout").
* Popover: Multi-line rich content cards positioned relative to anchors containing options or lists (Component 05).
* Modal: Viewport-blocking central dialogs requiring dismissal actions (Component 29).

2. Drawer vs. Sheet

* Drawer: Side menu slider panels anchored to the left/right boundaries (Component 03).
* Sheet: Bottom-anchored layouts designed for mobile interactions (Component 08).

3. Tab Deck vs. Panels

* Tab Deck: Horizontal state anchors switching nested views inside the same wrapper grid (Component 40).

🎨 CONTRAST GUIDELINES & WCAG AA

To maintain strict WCAG AA compliance, text components must maintain a contrast ratio of at least 4.5:1 against adjacent background blocks. Large header strings require a minimum ratio of 3:1. This ensures legibility for users with visual impairments. In our dark theme, we utilize `text-gray-200` (#e5e7eb) against `bg-darkBg` (#06080b) to exceed a 10:1 ratio.
