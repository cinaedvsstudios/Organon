**Why this overhaul exists:** The user selected 41 specific transitions from the original GL Transitions gallery. The renderer instead uses 2D Canvas animations named after those references and frequently omits their defining optics, physical behavior and original shader parameters. Many independently named visual overlays are also static graphics/rectangles merely sliding across the screen. The user expressly rejects declaring them complete based on name coverage or 'pixels changed' tests.
