**Why this overhaul exists:** The user selected 41 specific transitions from the original GL Transitions gallery. Many independently named visual overlays are also static graphics/rectangles merely sliding across the screen. The user expressly rejects declaring them complete based on name coverage or 'pixels changed' tests.
