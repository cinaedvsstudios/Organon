Organon Advanced Audio Timeline v0.14

This package contains Advanced Mode only plus the untouched Basic Mode index.html.

New in v0.14:
- Per-layer opacity controls for video, stickers and JPEG backgrounds.
- Pixel-based timeline coordinates: clips no longer recalculate their percentage position while you trim them.
- Timeline zoom slider (25%–400%) and reset button.
- Colour-matched lane titles: video blue, audio red, sticker/background gold.

Use the entire extracted folder, including js/. Open it through the Organon hub as before.
