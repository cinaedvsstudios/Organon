AUDIO TIMELINE — ADVANCED MODE v0.22

Install the complete contents of this package into the existing tools/audio-timeline/ folder, keeping the js/ folder beside advanced.html.

Important:
- Basic Mode is unchanged.
- Drop new File Explorer/Finder files anywhere over Advanced Mode or directly over Project Files. They import only to Project Files.
- Drag Project File pills to the timeline separately to create clips.
- Peak brightness is source-time anchored. Trimming a clip crops visible peaks; it never changes playback speed or squeezes the source analysis into a smaller width.

Rollback baseline: v0.21.
