1. CROSS-IFRAME POSTMESSAGE SPECIFICATION

Individual pages nested inside the Central Hub's iframe can easily transmit mouseover status messages back to the parent container's centered status board. This preserves interactive continuity throughout the user journey.

Register a message callback inside any sub-tool by pasting the following script:

// Broadcast description text dynamically to the Organon status center
function setHubStatus(text) {
  window.parent.postMessage({ type: 'set-status', text: text }, '*');
}

// Clear current message and restore default "ORGANON ONLINE" fallback
function clearHubStatus() {
  window.parent.postMessage({ type: 'clear-status' }, '*');
}

Standard Implementation:

const uploadButton = document.getElementById('image-upload');

uploadButton.addEventListener('mouseenter', () => {
  setHubStatus('Load a target asset from your device into the coordinate slicer workspace.');
});

uploadButton.addEventListener('mouseleave', () => {
  clearHubStatus();
});

2. GLOBAL SETTINGS BACKUP & STORAGE STRATEGY

To prevent bloated storage and disjointed favorites lists across the toolsuite, all sub-pages read and write directly to standard browser localStorage keys.

The Master Hub consolidates these databases through the settings cog modal, offering two distinct import behaviors:

Protocol Option Visual Theme Color Operational Execution
Import (Merge) Sand Ochre Combines keys in the uploaded file directly with existing browser data, overwriting duplicates but keeping other variables safe.
Import (Replace) Red Glow Clears all browser localStorage completely before rebuilding the variables table from the ground up using the loaded .json package.
Purge Crimson Danger Completely erases all saved tools, options, and states from the device, triggering a system hard reboot.
