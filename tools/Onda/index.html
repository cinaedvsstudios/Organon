▣ Streaming Direct audio works inside Onda. Other providers use embeds, external search, or saved references.
Playable in Onda when the URL is a direct audio file or stream.

Direct Audio URL

Best option: paste a direct mp3, wav, ogg, m4a, stream URL, or Google Drive direct/download link. Preview plays through Onda. Add to Library is manual so random pasted URLs do not pollute your catalogue.

SoundCloud

SoundCloud supports embedded playback through its official widget. Onda can save the link/reference; direct downloading only exists where SoundCloud itself exposes a download action.

Search YouTube

YouTube search opens external results. Specific video links can be embedded only when the video allows embedding.

Play YouTube URL

Spotify

Spotify can be embedded as a preview/reference. Full web playback requires Spotify account features, and proper browser playback generally requires Spotify Premium. This does not download MP3 files.

Apple Music

Apple Music links can be saved as references. Full playback needs MusicKit/account/developer-token work later, so this provider is reference-first for now.
