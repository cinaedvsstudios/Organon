What the code investigation established

These are implementation findings, not changes to the player:

  • Visualiser: v3.11 now stops scheduling continuous frames while paused or hidden; Android battery impact still needs measuring.
  • Local media: v3.13 adds optional Remember Files/Folder actions and a separate read-only handle database. Existing audio remains cached; Android permission persistence still needs testing.
  • Storage Health: v3.14 adds an on-demand read-only report for unlinked cached files and potential duplicate recordings, without any delete controls. Android testing remains open.
  • Now Playing / Queue: v3.15 displays the actual active queue on Current for named or ad-hoc playback, with Play, inline Info, Add to Playlist and queue-only Remove. Position resume remains optional P3.
  • Drawer: some mobile-view controls are referenced in JavaScript/CSS but not in static HTML; actual phone layout needs verification.
  • Cloud: existing Netlify sync backs up JSON, not audio. Future online media is planned on public GitHub Pages, with a JSON catalogue and playable files.
  • Home-screen icon: approved circular icon is configured; Chrome installed-mode validation and a native 512 PNG remain open.
