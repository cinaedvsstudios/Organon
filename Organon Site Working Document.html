2. Interactive Layout Specs & Timing Rules

⏱️

2-Second Hover Verification Delay

When a mouse hovers over the .divider-l1-l2 trigger bar, the system registers a 2000ms delay. If the cursor leaves prior to completion, the process is cancelled. This filters accidental sweeps and prevents annoying vertical shifting of your central content iframe.

📱

Double-Tap / Toggle Close Lock

Clicking or tapping the trigger bar instantly forces the menus open, bypassing the hover delay. A second tap on the bar instantly collapses the folders back into the sandstone header. Similarly, in sub-tools, double-clicking the countdown circle locks the panel open (🔒) to freeze automated closing states.

🔄

5-Second Persistence Watch

Once open, leaving active menu boundaries starts a 5-second countdown timer shown with a circular radial visual progress ring. Re-entering any active control panel freezes and resets the clock.

5. AI Sub-App Generation Specification

Feed this master specification page directly into any generative AI model to build a compatible Organon sub-app. The generated module must strictly follow these structural and design directives:

  • Structural Wrapper: Constrain the page layout to .app-wrapper with a maximum width of 540px, centered horizontally on the screen against a solid --bg-nightsky background.
  • Three-Panel Layout:
    • Panel 1 (Top Panel): position: sticky; top: 0; with a sandstone texture background map ../../Images/stonetext.jpg (strictly capital "I") layered over a translucent gold filter. Use a 5 -> 0 second countdown circle that collapses the sticky bar into a minimalist header unless hovered, clicked, or locked (🔒) via double-click.
    • Panel 2 (Middle Scrollable Panel): Pure black (#000000) background containing configuration elements, rounded card segments, and a deep bottom-padding offset of 120px.
    • Panel 3 (Bottom Panel): Fixed sticky layout at the bottom of the viewport carrying a low-transparency dark action button.
  • Tactile Components: Use fully rounded pills (border-radius: 9999px) for input fields, textareas, selection dropdown lists, and interactive buttons. Hide native numerical spin arrows. Use range sliders with active ruby-pink (#9a2f4f) tracks and dark burgundy (#61112e) inactive track tracks.
  • Handshake APIs: Integrate postMessage callbacks (setHubStatus(text) / clearHubStatus()) to broadcast action logs dynamically back to the parent Hub. Include the relative path top-level iframe guard redirecting users to ../../index.html if launched directly.

6. Cross-Iframe API Specs

Sub-tools communicate descriptions, errors, and success updates back to the parent hub status bar using postMessages. Here is the active JS framework for your tools: 

// Broadcast to Organon Hub Centered Status Bar
function setHubStatus(text) {
  window.parent.postMessage({ type: 'set-status', text: text }, '*');
}

// Clear status bar and restore "ORGANON ONLINE"
function clearHubStatus() {
  window.parent.postMessage({ type: 'clear-status' }, '*');
}

        function registerHoverDescription(selector, descriptionText) {
            const element = document.querySelector(selector);
            if (!element) return;
            element.addEventListener('mouseenter', () => {
                if (window.parent && window.parent.postMessage) {
                    window.parent.postMessage({ type: 'set-status', text: descriptionText }, '*');
                }
            });
            element.addEventListener('mouseleave', () => {
                if (window.parent && window.parent.postMessage) {
                    window.parent.postMessage({ type: 'clear-status' }, '*');
                }

        const topStickyPanel = document.querySelector(".top-sticky-panel");
        const countdownCircle = document.getElementById("countdown-circle");
        let countdownVal = 5;
        let countdownInterval = null;
        let isPanelLocked = false;
        let isHoveringPanel = false;

        function updateCircleDisplay() {
            countdownCircle.innerHTML = isPanelLocked ? "🔒" : countdownVal;
        }

        function startCountdown() {
            if (isPanelLocked || isHoveringPanel) return;
            clearInterval(countdownInterval);
            countdownInterval = setInterval(() => {
                countdownVal--;
                updateCircleDisplay();
                if (countdownVal <= 0) {
                    clearInterval(countdownInterval);
                    topStickyPanel.classList.add("minimized");
                }
            }, 1000);
        }

        function resetCountdown() {
            clearInterval(countdownInterval);
            countdownVal = 5;
            updateCircleDisplay();
        }

        function minimizePanel() {
            topStickyPanel.classList.add("minimized");
        }

        function maximizePanel() {
            topStickyPanel.classList.remove("minimized");
            resetCountdown();
        }

        topStickyPanel.addEventListener("mouseenter", () => {
            isHoveringPanel = true;
            maximizePanel();
            clearInterval(countdownInterval);
        });

        topStickyPanel.addEventListener("mouseleave", () => {
            isHoveringPanel = false;
            resetCountdown();
            startCountdown();

            if (topStickyPanel.classList.contains("minimized")) {
                maximizePanel();
            }
        });

        countdownCircle.addEventListener("dblclick", (e) => {
            e.stopPropagation();
            e.preventDefault();
            isPanelLocked = !isPanelLocked;
            updateCircleDisplay();
            if (isPanelLocked) {
                clearInterval(countdownInterval);
                maximizePanel();
            } else {
                if (!isHoveringPanel) {
                    startCountdown();
                }
            }
